# MySQL 流程控制

记于 2026.11.18

MySQL 里写存储过程函数时也要用判断和循环，语法跟编程语言像但细节不同。这些都是写在 BEGIN...END 里的，普通 SQL 窗口单用没意义。

## IF 分支

注意结尾有 **END IF**，中间的 ELSEIF 是一个词连写（Java 是 else if，这里分开写就报错）：

```sql
IF 条件 THEN 语句;
ELSEIF 条件2 THEN 语句;
ELSE 语句;
END IF;
```

## CASE 分支

两种写法：跟值比较、跟条件比较。END 后面要跟 **CASE** 收尾：

```sql
-- 1. 等值判断，类似 switch
CASE 变量
    WHEN 1 THEN 语句;
    WHEN 2 THEN 语句;
    ELSE 语句;
END CASE;

-- 2. 条件判断，CASE 后面不跟东西
CASE
    WHEN 条件 THEN 语句;
    WHEN 条件 THEN 语句;
    ELSE 语句;
END CASE;
```

ELSE 不写的话，都不匹配直接报错（不是跳过），这个跟编程语言不一样，容易出错。

## WHILE 循环

先判断再执行，条件不满足一次都不跑：

```sql
WHILE i <= n DO
    SET s = s + i;
    SET i = i + 1;
END WHILE;
```

## LOOP 循环

没有条件的循环，**必须配 LEAVE 跳出去**，否则死循环：

```sql
myloop: LOOP            -- 循环标签
    SET i = i + 1;
    IF i > n THEN
        LEAVE myloop;   -- 相当于 break
    END IF;
END LOOP myloop;
```

## REPEAT 循环

先干一遍再判断，至少跑一次，类似 do-while。区别是 UNTIL 条件**成立就退出**（跟 WHILE 相反）：

```sql
REPEAT
    SET s = s + i;
    SET i = i + 1;
UNTIL i > n END REPEAT;
```

## LEAVE 和 ITERATE

- **LEAVE 标签**：跳出整个循环，等于 break
- **ITERATE 标签**：跳过本轮剩下的语句直接进下一轮，等于 continue

两个都得靠前面的标签指路，所以循环体里想用控制流，循环就必须有标签：

```sql
addnum: LOOP
    SET i = i + 1;
    IF i % 2 = 1 THEN ITERATE addnum; END IF;   -- 奇数跳过
    IF i > n THEN LEAVE addnum; END IF;          -- 超了退出
    SET s = s + i;
END LOOP addnum;
```

## 三种循环怎么选

- 知道大概跑几次 → WHILE（或 REPEAT）
- 至少要执行一次 → REPEAT
- 条件在循环体中间才确定 → LOOP + LEAVE

LOOP 需要标签配合 LEAVE 使用，WHILE 条件前置写法更直接，多数场景用 WHILE。
