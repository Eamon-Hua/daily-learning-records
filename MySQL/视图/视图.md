# MySQL 视图

记于 2026.11.16

视图就是**把一段常用查询存起来当表用**。数据还是原表的，视图里不存数据，所以也叫虚拟表。

## 创建和查看

```sql
CREATE VIEW v1 AS
SELECT empno, ename, deptno FROM emp;

SELECT * FROM v1;        -- 当表查
DESC v1;                 -- 看结构
SHOW CREATE VIEW v1;     -- 看建视图的语句
```

视图里可以 JOIN 多表，复杂的关联查询存成视图，以后一行 `SELECT * FROM v2` 搞定，这是它最大的价值。

## 修改视图

两种写法，效果一样：

```sql
CREATE OR REPLACE VIEW v1 AS
SELECT empno, ename, salary FROM emp;   -- 有就替换，没有就新建

ALTER VIEW v1 AS
SELECT empno, ename FROM emp;           -- 只改已有的
```

## 删除视图

```sql
DROP VIEW v1;
DROP VIEW IF EXISTS v1;   -- 建议带 IF EXISTS，不存在也不报错
```

删视图**不影响原表**，视图本身不存数据。

## 视图也能增删改，改的是原表

```sql
UPDATE v1 SET ename = '赵六' WHERE empno = 1;
INSERT INTO v1(empno, ename) VALUES(4, '孙七');
DELETE FROM v1 WHERE empno = 4;
```

操作视图就是操作背后的表，原表数据会真的变。

## 但不是什么视图都能更新

带下面这些东西的视图**只读**，增删改会报错：

- 聚合函数（SUM、AVG、COUNT…）
- GROUP BY / HAVING
- DISTINCT
- UNION

原因：聚合后的视图行找不到原表里对应的行，无法定位要修改的数据。

```sql
CREATE VIEW v3 AS
SELECT deptno, AVG(salary) avg_sal FROM emp GROUP BY deptno;

UPDATE v3 SET avg_sal = 1 WHERE deptno = 10;   -- 报错
```

## WITH CHECK OPTION

给视图加约束：通过视图插/改的数据，**必须还能从视图查出来**，不然拒绝写入。

```sql
CREATE VIEW v4 AS
SELECT empno, ename, deptno FROM emp WHERE deptno = 10
WITH CHECK OPTION;

INSERT INTO v4(empno, ename, deptno) VALUES(5, '周八', 10);   -- OK
INSERT INTO v4(empno, ename, deptno) VALUES(6, '吴九', 20);   -- 报错，20 不在视图条件里
```

不加这个的话第二条能插进去，只是插完在视图里查不到——数据进了原表但视图看不到，一般不是想要的效果。
