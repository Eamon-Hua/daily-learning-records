# Java 集合

记于 2026.11.20

数组长度定死，集合就是**长度自动扩、还能装各种数据结构**的替代品。顶层是 Collection 和 Map 两条线：Collection 单个单个装，Map 一对一对（键值）装。

## List：有序可重复

ArrayList 和 LinkedList 都实现了 List，区别在底层结构：

- **ArrayList**：底层是数组。查快（下标直接定位），中间插删慢（后面元素全要挪）
- **LinkedList**：底层是双向链表。头尾插删快，查也慢（得从头一个个捋）

实际开发 90% 的场景用 ArrayList——查询远多于插删，而且它是连续内存，缓存友好。

```java
List<String> list = new ArrayList<>();
list.add("a");                    // 追加
list.add(0, "头");                // 指定位置插
list.get(0);                      // 取下标
list.set(0, "替换");              // 改
list.remove(0);                   // 按下标删
list.size();                      // 个数
list.contains("a");               // 有没有
```

一个容易忽略的重载坑：list 里存 Integer 的时候，`remove(1)` 删的是**下标 1** 不是数字 1，想按对象删要写 `remove(Integer.valueOf(1))`。

## Set：不可重复

HashSet 最常用，底层是 HashMap（值都是同一个占位对象）。**无序、不可重复**，加进去的顺序和遍历出来的顺序没关系：

```java
Set<String> set = new HashSet<>();
set.add("a");
set.add("a");          // 加不进去，返回false，集合里还是1个
```

去重判断靠 hashCode + equals：先看哈希值在不在桶里，在再 equals 确认。所以自定义类想正确去重，**hashCode 和 equals 必须一起重写**，只重写一个去重就是坏的。

要保留插入顺序用 LinkedHashSet，要排序用 TreeSet（按自然序或比较器自动排）。

## Map：键值对

HashMap 键不可重复，键值一一对应：

```java
Map<String, Integer> m = new HashMap<>();
m.put("语文", 95);          // 放，键重复就是覆盖旧值
m.get("语文");              // 95，键不存在返回null
m.remove("语文");
m.containsKey("语文");      // 有没有这个键
m.size();
```

遍历三种写法：

```java
// 1. entrySet 一把抓键值，最推荐
for (Map.Entry<String, Integer> e : m.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}

// 2. 只要键
for (String k : m.keySet()) {
    System.out.println(k + "=" + m.get(k));
}

// 3. 只要值
for (Integer v : m.values()) { }
```

get 一个不存在的键返回 null 而不是报错，容易埋下空指针，拿值前先 containsKey 或者用 `getOrDefault(k, 默认值)`。

HashMap 和 HashSet 一样无序；要排序用 TreeMap，要保插入顺序用 LinkedHashMap。

## 三兄弟怎么选

- 键值映射（学号→学生）：Map
- 允许重复、要下标：List
- 只存不重复的一堆：Set
