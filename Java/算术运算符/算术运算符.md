# 算术运算符

记于 2026.11.15

一共就 7 个：`+ - * / % ++ --`，都认识，但真写起来坑不少。这两天踩的记一下。

| 符号 | 干啥的 | 例子 |
| --- | --- | --- |
| + | 加，另外还能拼字符串 | 7+2=9 |
| - | 减 | 7-2=5 |
| * | 乘 | 7*2=14 |
| / | 除，整数除会丢小数 | 7/2=3 |
| % | 取余 | 7%2=1 |
| ++ | 自己加 1 | a++ |
| -- | 自己减 1 | a-- |

## 7/2 得 3

第一次写 `7/2` 想拿 3.5，打印出来是 3，还以为环境坏了。

```java
System.out.println(7 / 2);          // 3
System.out.println(7 / 2 * 1.0);    // 3.0   先除完了再乘，晚了
System.out.println(7 / (double) 2); // 3.5   要小数就只能先转一个
```

## 取余的符号跟左边走

这个跟数学课上的余数不一样，`-5 % 2` 是 -1，不是 1。

```java
System.out.println(5 % 2);    // 1
System.out.println(-5 % 2);   // -1   看左边（被除数）
System.out.println(5 % -2);   // 1    结果符号跟左边（被除数）一致
System.out.println(-5 % -2);  // -1
```

平时用得最多的就是判断奇偶：`n % 2 == 0`。

## 类型会自己往上走

小的跟大的算，结果变成大的。byte、short、char 这仨只要参与运算，一律先变 int。

```java
int i = 10;
double d = 3;
System.out.println(i + d);   // 13.0

char c = 'a';
System.out.println(c + 1);         // 98    'a' 是 97
System.out.println((char)(c + 1)); // b

byte x = 1, y = 2;
// byte z = x + y;   编译不过，byte 加完变 int 了
byte z = (byte)(x + y);
```

## 小数算不准

`0.1 + 0.2` 不等于 0.3，这个不是 Java 的问题，用二进制的语言都这样。

```java
System.out.println(0.1 + 0.2);        // 0.30000000000000004
System.out.println(0.1 + 0.2 == 0.3); // false
```

所以判断小数别用 `==`。金额计算用 BigDecimal。

## 加号碰到字符串就变拼接

这个我写打印日志的时候坑过一次，`"总数：" + 1 + 2` 出来是 "总数：12" 不是 3。

```java
System.out.println("10" + 20);      // 1020
System.out.println(10 + 20 + "30"); // 3030    前面是数字，先加
System.out.println("10" + 20 + 30); // 102030  一旦变成字符串，后面全拼
System.out.println('a' + 1 + "b");  // 98b
System.out.println("" + 'a' + 1);   // a1
```

## 自增：++ 在前在后不一样

单独一行写 `i++` 和 `++i` 没区别，但只要参与赋值、打印，就得分清楚。

```java
int m = 5;
int r1 = m++;   // 先把 5 给 r1，m 再加 1     r1=5, m=6

int k = 5;
int r2 = ++k;   // k 先变 6，再把 6 给 r2     r2=6, k=6
```

口诀：**在前先加，在后后加**。

## i = i++ 等于几

这题想了挺久。答案是原值，10 还是 10。

```java
int t = 10;
t = t++;
System.out.println(t);   // 10   不是 11
```

拆开就是：右边 `t++` 先把 10 存到临时变量里，t 自己变 11，然后把临时变量里的 10 赋回去，又变回 10。自增白干。

`t = ++t` 才是 11，因为前缀是先加完再赋值。

## += 自带强转

这条是看面试题才知道的。`short s = 1; s = s + 1;` 编译不过，但 `s += 1;` 能过，因为 `+=` 内部自带强制类型转换。

```java
short s = 1;
// s = s + 1;   报错：int 不能直接塞回 short
s += 1;         // 没问题，等于 s = (short)(s + 1)
```

## 溢出不会报错

`Integer.MAX_VALUE` 加 1 直接变最小值，一点提示都没有。

```java
int max = Integer.MAX_VALUE;
System.out.println(max);           // 2147483647
System.out.println(max + 1);       // -2147483648
System.out.println((long)max + 1); // 2147483648  先转 long 就没事
```

## 除以 0 分两种

整数除 0 直接抛异常，浮点除 0 给个 Infinity，不报错。

```java
// System.out.println(1 / 0);   // ArithmeticException
System.out.println(1.0 / 0);  // Infinity
System.out.println(0.0 / 0);  // NaN
```

NaN 的特性是它跟谁都不相等，包括自己，所以判断得用 `Double.isNaN`。

## 优先级

括号最优先，然后乘除取余，最后加减，同级从左往右。

```java
System.out.println(2 + 3 * 4);   // 14
System.out.println((2 + 3) * 4); // 20
System.out.println(10 - 3 - 2);  // 5   不是 10-(3-2)
System.out.println(-7 / 2);      // -3  往零那边取整
```

拿不准就加括号，别背。
