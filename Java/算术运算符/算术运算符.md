# 算术运算符（Arithmetic Operators）

> 📌 本文是个人自学 Java 基础的学习笔记，采用**费曼学习法**：先自己讲明白，再整理输出。所有代码均已实际运行验证，注释里的输出与真实运行结果一致。

## 📖 文档简介

💡 算术运算符是 Java 里最先接触、也最容易踩坑的一类运算符。一共就 **7 个**：`+ - * / % ++ --`，看着简单，但整除、取模符号、类型提升、字符串拼接、i=i++ 这些坑全藏在这里面。

🔔 适用人群：Java 零基础初学者、准备面试需要复盘基础的人。

---

## 一、运算符总览

| 运算符 | 含义 | 示例 | 结果 |
| :---: | :--- | :--- | :---: |
| `+` | 加法 / 正号 / **字符串拼接** | `7 + 2` | `9` |
| `-` | 减法 / 负号 | `7 - 2` | `5` |
| `*` | 乘法 | `7 * 2` | `14` |
| `/` | 除法（整数相除会**丢小数**） | `7 / 2` | `3` |
| `%` | 取模（求余数） | `7 % 2` | `1` |
| `++` | 自增 1 | `a++` / `++a` | — |
| `--` | 自减 1 | `a--` / `--a` | — |

## 二、核心规则（面试高频）

### 2.1 整数相除，小数直接砍掉

```java
System.out.println(7 / 2);           // 3    不是四舍五入，是直接砍
System.out.println(7 / 2 * 1.0);     // 3.0  坑：先算了 7/2=3，再乘 1.0 已经晚了
System.out.println(7 / (double) 2);  // 3.5  想要小数，必须让一边先变成浮点型
```

### 2.2 取模的符号只看被除数（左边）

```java
System.out.println(5 % 2);    //  1
System.out.println(-5 % 2);   // -1   左边是负的，结果就是负的
System.out.println(5 % -2);   //  1   右边是负的，不影响
System.out.println(-5 % -2);  // -1
```

> ✅ 记忆口诀：**余数的符号跟着被除数走**。和数学里的"余数必须非负"不是一回事。

常用场景：判断奇偶 `n % 2 == 0`、判断整除 `n % m == 0`。

### 2.3 类型自动提升

规则：**小的类型和大的类型一起运算，结果自动变成大的类型**。`byte/short/char` 运算时一律先提升成 `int`。

```java
int i = 10;
double d = 3;
System.out.println(i + d);   // 13.0  int 先转 double 再加

char c = 'a';
System.out.println(c + 1);         // 98   'a' 就是 97
System.out.println((char)(c + 1)); // b    想变回字符要自己强转

byte x = 1, y = 2;
// byte z = x + y;        编译不过！byte 相加自动升成 int
byte z = (byte)(x + y);   // 必须强转回来
```

### 2.4 浮点数算不准（这是常识，不是 bug）

```java
System.out.println(0.1 + 0.2);       // 0.30000000000000004
System.out.println(0.1 + 0.2 == 0.3); // false  千万别用 == 比浮点数
```

> 🔔 涉及金额计算用 `BigDecimal`，不要用 `double`。

### 2.5 `+` 碰上字符串就变成拼接

规则：`+` 两边**只要有一个是字符串，就是拼接**；运算顺序**从左往右**。

```java
System.out.println("10" + 20);      // 1020
System.out.println(10 + 20 + "30"); // 3030    先算加法，再拼接
System.out.println("10" + 20 + 30); // 102030  先拼接，后面全变字符串
System.out.println('a' + 1 + "b");  // 98b     char+int 先算加法
System.out.println("" + 'a' + 1);   // a1      一旦变字符串，后面全拼
```

### 2.6 自增自减：单独用没区别，参与运算才见真章

```java
int m = 5;
int r1 = m++;   // 后缀：先把 5 交出去，m 再变 6     → r1=5, m=6

int k = 5;
int r2 = ++k;   // 前缀：k 先变 6，再把 6 交出去     → r2=6, k=6
```

> ✅ 一句话：**前缀先加后用，后缀先用后加**。单独一行写 `i++;` 时两者完全等价，为了可读性建议单独写。

### 2.7 经典面试题：`i = i++` 等于几？

```java
int t = 10;
t = t++;
System.out.println(t);   // 10   不是 11！
```

**拆解过程**：

1. 右边 `t++` 是后缀：先把 10 这个值**存起来**（临时变量），t 自己变成 11
2. 再把存起来的 **10** 赋回给 t
3. t 最终 = 10，自增白干了一场

```java
int u = 10;
u = ++u;
System.out.println(u);   // 11   前缀先加再赋值，这次没白干
```

### 2.8 复合赋值运算符自带强制类型转换

`+= -= *= /= %=` 内部**隐含了一次强转**，这是它们和"展开写"的唯一区别。

```java
short s2 = 1;
// s2 = s2 + 1;   编译不过：short + int 结果是 int
s2 += 1;          // 编译通过！等价于 s2 = (short)(s2 + 1)
```

这也是经典面试题 `short s1 = 1; s1 += 1;` 能编译通过、`s1 = s1 + 1;` 不能的原因。

### 2.9 溢出：装不下就绕回去，不会报错

```java
int max = Integer.MAX_VALUE;
System.out.println(max);          // 2147483647
System.out.println(max + 1);      // -2147483648  最大值加 1 变最小值
System.out.println((long)max + 1); // 2147483648  先转 long 可防溢出
```

### 2.10 除零：整数和浮点完全两码事

```java
// System.out.println(1 / 0);   // ArithmeticException: / by zero  整数除零抛异常
System.out.println(1.0 / 0);    // Infinity    浮点除零是无穷大
System.out.println(-1.0 / 0);   // -Infinity
System.out.println(0.0 / 0);    // NaN         零除零"不是一个数"

System.out.println(0.0 / 0 == 0.0 / 0);        // false  NaN 连自己都不等于
System.out.println(Double.isNaN(0.0 / 0));     // true   判断要用 isNaN
```

### 2.11 优先级：括号最大，先乘除后加减，同级从左往右

```java
System.out.println(2 + 3 * 4);    // 14
System.out.println((2 + 3) * 4);  // 20
System.out.println(10 - 3 - 2);   // 5    同级从左往右，不是 10-(3-2)
System.out.println(-7 / 2);       // -3   向零取整，不是 -4
```

## 三、易错点清单（自查）

- [ ] `7/2` 想当然认为等于 3.5（实际是 3）
- [ ] 认为 `-5 % 2` 等于 1（实际是 -1）
- [ ] `byte` 相加忘了自动升 `int`，编译报错看不懂
- [ ] 用 `==` 比较两个浮点数
- [ ] `"10" + 20 + 30` 以为会做加法（实际是拼接）
- [ ] `i = i++` 以为会加 1（实际不变）
- [ ] `s1 = s1 + 1` 和 `s1 += 1` 以为完全等价（后者自带强转）
- [ ] 整数除零以为和浮点除零一样返回特殊值（实际直接抛异常）
