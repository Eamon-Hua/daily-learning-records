# Java 泛型与迭代

记于 2026.11.20

泛型的作用：**把类型检查从运行期提前到编译期**。没有泛型时集合里什么类型都能塞，取的时候还得强转，类型错了运行期才报错；加了泛型 `<String>`，塞别的编译都过不了。

## 泛型集合

```java
List<String> list = new ArrayList<>();
list.add("a");
list.add(123);        // 编译报错，运行前就拦住
String s = list.get(0);   // 取出来不用强转
```

注意 <> 里只能写引用类型，int 得写 Integer。右边 new 的时候 `<>` 留空就行（钻石操作符），编译器自己推断。

## 泛型类

类名后面挂 <T>，T 是占位符，用的时候才确定：

```java
class 盒子<T> {
    private T 东西;

    public void 放(T 东西) { this.东西 = 东西; }
    public T 拿() { return 东西; }
}

盒子<String> b1 = new 盒子<>();    // 这个盒子只装String
盒子<Integer> b2 = new 盒子<>();   // 这个只装Integer
```

T 只是习惯写法（Type），叫什么都行。要多个占位符就 `<T, E>` 一个类里随便用。

## 泛型方法

方法自己声明类型参数，跟类上的泛型无关，调用时由实参推断：

```java
public <T> void 打印(T x) {
    System.out.println(x);
}

打印("串");      // T推断成String
打印(123);       // T推断成Integer，同一个方法全兼容
```

`<T>` 写在返回值前面，这是它和"方法用了类上的 T"的区别——泛型方法自带声明。

## 泛型的边界

如果 T 必须有某类的能力，用 extends 限定上限：

```java
class 数字盒子<T extends Number> { }   // T只能是Number或其子类
```

另外泛型不支持多态那套继承代入：`盒子<Animal>` 不能接 `盒子<Dog>`，因为盒子不是协变的。想通吃所有类型的盒子，用通配符 `<?>` 或上限通配符 `<? extends Number>`。

## 增强 for 和 Iterator

增强 for 底层就是 Iterator，写法短，只读遍历用它：

```java
for (String s : list) {
    System.out.println(s);
}
```

Iterator 是正经的迭代器，三个方法：hasNext() 有没有下一个、next() 取下一个并后移、remove() 删当前这个：

```java
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if ("b".equals(s)) {
        it.remove();      // 唯一安全的边遍历边删方式
    }
}
```

**边遍历边改集合必须用 it.remove()**。用 list.remove() 去删，集合内部有个修改次数计数器，迭代器和集合的次数对不上就抛 ConcurrentModificationException。细节是 JDK 25 起放宽了一档：删"刚访问过"或正好压在光标位置的元素不再抛异常，但删光标后面的元素、遍历中 add 照样抛异常——统一用 it.remove() 最稳。增强 for 里也一样不能 add/remove。

过滤删除有更简洁的写法：`list.removeIf(s -> s.equals("b"))`，一句顶 while 循环。
