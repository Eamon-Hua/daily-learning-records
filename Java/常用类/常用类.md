# Java 常用类

记于 2026.11.19

String 天天用但坑最多，日期 API 只记 Java 8 之后的新方案，老的 Date 和 Calendar 不再推荐。

## String：不可变

String 底层是 final 的 char 数组（Java 9 之后是 byte 数组），**一旦创建内容就改不了**。看起来在"改"的操作全都是造了新对象：

```java
String s = "abc";
s = s + "d";    // 不是改了s，是造了个新对象"abcd"再把引用换过去
```

所以循环里拼字符串会创建大量临时对象，这种场景换 StringBuilder。

字符串常量池："abc" 这种字面量进常量池，同样的字面量共享一个对象，所以 `==` 比两个相同字面量是 true。但 new 出来的在堆里，`==` 就比的是地址了，**比较内容永远用 equals**：

```java
String a = "abc";
String b = new String("abc");
a == b;        // false，地址不同
a.equals(b);   // true，比内容
```

## 常用方法速记

```java
s.length();              // 长度
s.charAt(0);             // 取第几个字符
s.indexOf("b");          // 找位置，找不到返回-1
s.substring(1, 3);       // 截取[1,3)，包头不包尾
s.replace("a", "x");     // 替换，返回新串
s.split(",");            // 切成数组，注意.和|这类要转义
s.trim();                // 去首尾空格
s.toUpperCase();         // 转大写
s.contains("bc");        // 包含判断
s.isEmpty();             // 是不是""
```

split 的坑：按 `.` 切要写成 `split("\\.")`，正则里 `.` 是任意字符，忘了转义切出来是个空数组。

## StringBuilder：要拼就用它

可变的字符序列，内部数组不够自动扩容，拼完 `toString()` 转回 String：

```java
StringBuilder sb = new StringBuilder();
sb.append("a").append("b").append(1);   // 链式调用，都返回自己
sb.reverse();                            // 反转
String s = sb.toString();
```

什么时候用哪个：单次拼接 String 没问题，**循环里拼、长文本拼，一律 StringBuilder**。StringBuffer 功能一样但方法都加了 synchronized，单线程下没必要，不用。

## 日期时间 API（java.time）

老的 Date 和 Calendar 缺点多（月份从 0 开始、可变、线程不安全），Java 8 起用 java.time 包，常用三个：

```java
LocalDate d = LocalDate.now();          // 2026-11-19，只有日期
LocalDateTime t = LocalDateTime.now();  // 2026-11-19T20:15:30.123，日期加时间

LocalDate 生日 = LocalDate.of(2005, 2, 8);
d.isAfter(生日);          // 日期比较
d.plusDays(7);            // 加7天，返回新对象不改原值
生日.getYear();           // 2005
```

这套 API 全是不可变设计，加加减减都返回新对象，跟 String 一样。

格式化用 DateTimeFormatter，**线程安全**，可以定义成常量到处用：

```java
DateTimeFormatter f = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String s = t.format(f);                    // 2026-11-19 20:15:30
LocalDateTime back = LocalDateTime.parse(s, f);   // 字符串转回来，格式必须完全对上
```

pattern 里 MM 是月 mm 是分钟，写混了 parse 直接报错。
