# 静态（static）

记于 2026.11.16

static 就是告诉 Java：**这个成员属于类，不属于某个对象**。不管 new 多少个，静态的就那一份。能修饰的就三个东西：变量、方法、代码块。

## 静态变量：所有对象共享一份

```java
class 学员 {
    String name;
    static String 学校 = "北大";   // 一份，所有学生共享
    static int 人数 = 0;

    public 学生(String name) {
        this.name = name;
        人数++;                     // 每创建一个对象加 1
    }
}
```

```java
学生 s1 = new 学员("张三");
学生 s2 = new 学员("李四");
学生.学校 = "清华";    // 正式写法：类名.静态变量
System.out.println(s1.学校);   // 清华，s2 也跟着变了
```

对象改了静态变量，别的对象读到的也是改过的，因为本来就是同一个变量。

访问建议用 `类名.静态变量`，用 `对象.静态变量` 也能跑，但 IDEA 会画黄线提醒你，容易让人误以为这是这个对象自己的。

## 静态方法：不用 new 就能调

工具类的方法通常都是静态的，`Math.max()` 就是这样：

```java
class 工具 {
    public static int 最大值(int a, int b) {
        return a >= b ? a : b;
    }
}

工具.最大值(3, 7);   // 直接类名调，不用 new
```

**静态方法里没有 this**，所以它不能直接访问非静态成员：

```java
class 测试 {
    String name;
    static void 打印() {
        // System.out.println(name);   编译不过！静态方法没有对象
    }
}
```

原因：非静态成员属于对象，静态方法被调用时可能还没有任何对象，访问不到 name。反过来，非静态方法里用静态成员完全没问题。

## 静态代码块：类加载时跑一次

```java
class 配置 {
    static String 值;

    static {
        System.out.println("配置加载好了");
        值 = "默认";
    }
}
```

第一次用到这个类（new 它或者访问它的静态成员）时执行，**之后再也不执行**。哪怕 new 十个对象，代码块也只跑一次。

典型用途：加载配置文件、初始化静态变量。多个静态块按写的顺序执行。

## 什么时候用 static

- 所有对象都一样的值 → 静态变量（比如默认学校、圆周率）
- 不需要对象状态的方法 → 静态方法（工具类）
- 类加载时要做一次的事 → 静态代码块

判断标准：**跟单个对象无关，就用 static。**
